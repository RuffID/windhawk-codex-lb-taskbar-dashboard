# editor

Настройка подсказок clangd; это не система сборки мода.

- update-clangd.ps1 читает @compilerOptions, разбирает кавычки как Windhawk 1.7.3,
  проверяет include-путь проекта и создаёт compile_commands.json и .clangd.
- По умолчанию SourcePath — основной mod.wh.cpp в корне проекта. При передаче
  -SourcePath с путём EditorWorkspace/mod.wh.cpp база включает оба файла входа,
  а .clangd записывается также для указанной рабочей папки.
- CompilerRoot задаёт путь установленного компилятора Windhawk. На другом
  компьютере передавай актуальное значение; абсолютный путь самого проекта
  берётся только из @compilerOptions.
- compile_commands.json и .cache/ — локальные генерируемые данные, исключённые
  из Git. Не редактируй их вручную и не добавляй AGENTS.md внутрь кеша.

Команда из корня проекта для подсказок в редакторе Windhawk:

```powershell
& './editor/update-clangd.ps1' -SourcePath 'D:/Programs/Windhawk/AppData/EditorWorkspace/mod.wh.cpp' -CompilerRoot 'D:/Programs/Windhawk/Compiler'
```

Перед запуском скрипта агент обязан получить разрешение на точную команду.
Скрипт не запускает компилятор или мод. После обновления конфигурации можно
вручную выполнить в редакторе команду clangd: Restart language server.
Windhawk перезаписывает свой compile_flags.txt и .clang-format при инициализации
EditorWorkspace; .clangd и внешнюю базу он не создаёт. Его UI может автоматически
выполнять git init/add, поэтому не вызывай этот UI для проверки при запрете Git.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
