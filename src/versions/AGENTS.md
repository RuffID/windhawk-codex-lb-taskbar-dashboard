# versions

- semver.h: разбор версий, сравнение числовых core/prerelease-компонентов без
  переполнения, stable/prerelease и игнорирование build metadata для precedence.
- releases.h: разбор /api/runtime/version, выбор новейшего опубликованного
  GitHub-релиза (включая beta, без drafts), запросы и кеширование результата.
  Сохраняет оригинальный tag_name, включая v, для отображения и ссылки на релиз;
  SemVer-нормализация применяется только при сравнении.
- release_cache.h: UTC-срок следующего запроса, атомарная запись JSON-кеша в
  LOCALAPPDATA/CodexLbTaskbarDashboard/github-releases-v1.json и именованный
  Global mutex с именем по пути кеша. Блокировка удерживается на весь запрос,
  ожидание отменяется dashboard cancel event. В кеше нет учётных данных.

Popup сравнивает текущую версию с GitHub-релизами по SemVer: beta.10 > beta.9,
а stable > beta той же версии. Не подменяй сравнение лексикографическим.
Taskbar использует только latestUpdateAvailable из updateAvailable codex-lb,
независимо от GitHub-проверки. Ошибка проверки не означает актуальность версии.
Общий интервал — минимум 120 секунд; слот сохраняется до запроса и результат
после него. Manual refresh/reload не обходят срок. Другие процессы читают тот же
статус/тег. Ошибка кеша останавливает проверку, без несогласованного сетевого обхода.
429 либо 403 с remaining=0, Retry-After или сообщением о rate limit/abuse дают
RateLimited. Учитываются наиболее поздний Reset/Retry-After (секунды или HTTP-date)
и минимум 120 секунд; без подходящего срока пауза 3600 секунд. Обычный 403 — Failed.
Remaining=0 после успешного ответа тоже откладывает следующий запрос до Reset,
не превращая успех в ошибку; Retry-After учитывается также для других HTTP-ответов.
HTTP-date разбирается только для значения с запятой и суффиксом GMT, чтобы
переполненное число секунд не принималось либеральным WinHTTP-парсером за дату.
GitHub-запросы имеют отдельный URL/таймаут и пустые cookie/bearer.
При неудачной проверке Wh_Log выводит HTTP-статус, только JSON-поле message
и три заголовка лимитов (Remaining/Reset/Retry-After). Значения ограничены по длине,
управляющие символы заменяются пробелами, отсутствие данных отмечается явно.
Полное тело ответа, cookie и токены в диагностику не попадают; Reset — Unix seconds.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
