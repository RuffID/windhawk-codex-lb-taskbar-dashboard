# popup

window.h содержит показ/скрытие popup, его класс и оконную процедуру, mouse hook,
manual refresh, hover/pressed состояния, scrolling и закрытие снаружи.
Рисование делегируется ui/rendering/popup.h, обновление — core/refresh_api.h.

Сохраняй layered window, DPI-масштабирование, маршрутизацию между UI-потоками,
защиту от повторного открытия после внешнего клика и очистку ресурсов.
В заголовке отдельно отображаются «Текущая: …» и результат GitHub/beta-проверки,
адрес, остаток usage, версия мода и время успешного обновления.
Результат проверки показан в рамке под текущей версией: для ошибки/лимита красная
только рамка, для нового релиза — зелёная; текст и подчёркивание тега обычного цвета.
При отсутствии обновлений и рамка, и текст обычные. Лимит имеет отдельную надпись.
Значок GitHub справа от адреса открывает страницу /releases через shell32/ShellExecuteW.
Подпись версии — «Мод v.<версия>» с пробелом. Справа от измеренной подписи
второй значок GitHub ведёт на RuffID/windhawk-codex-lb-taskbar-dashboard;
области двух значков и тега независимы, место под значок зарезервировано в строке.
Области ссылок соответствуют последнему рисованию; открытие требует down/up
на одной ссылке, потеря capture отменяет нажатие. Сеть при рисовании не вызывается.
Состояние берётся snapshot под g_dashboardMutex. Не смешивай ошибки accounts,
runtime version и GitHub; отсутствие результата не трактуется как успех.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
