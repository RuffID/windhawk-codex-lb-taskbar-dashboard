# ui

- rendering: GDI/DIB отрисовка и компоновка popup.
- popup: HWND popup, оконные сообщения, мышь, прокрутка и закрытие.
- taskbar: XAML-виджеты панели задач, события, позиция и восстановление.

Сохраняй внешний вид и текущие условия отображения при архитектурных правках.
UI получает опубликованные данные под исходными mutex и использует
core/refresh_api.h для запроса обновления. Сеть и lifecycle сюда не переносить.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
