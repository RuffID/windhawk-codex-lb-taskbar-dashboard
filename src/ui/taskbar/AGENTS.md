# taskbar

widgets.h содержит обход XAML-дерева, поиск tray/root, создание и позиционирование
виджета, цветной процент, latest-индикатор, event revokers, reconciliation,
учёт корней primary/secondary taskbar и удаление виджетов вместе с popup.

Синий знак справа от процента зависит только от updateAvailable runtime codex-lb
(при известном проценте), а не от GitHub/beta. Не меняй пороги цветов/размеры.
Работай с XAML на соответствующем UI-потоке; сохраняй revokers, weak refs,
mutex и проверку замены tray/удаления виджета. Общие данные принадлежат core/state.h.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
