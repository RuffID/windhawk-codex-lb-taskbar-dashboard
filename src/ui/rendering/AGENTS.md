# rendering

popup.h владеет PaintGuard/GdiObjectGuard, константами компоновки, PopupCanvas,
DIB-пикселями, premultiplied alpha, отрисовкой текста/поверхностей, шрифтами,
масштабированием DPI, карточками, полосами лимитов, refresh button и scrollbar.

Сохраняй прозрачность поверхностей и непрозрачные внутренние пиксели глифов,
смешивание antialiased краёв, размеры/цвета/шрифты и выделение GDI-ресурсов с очисткой.
Reset (N) рисуется только при положительном количестве без reauth_required;
неизвестный срок скрывает только countdown. Цвет срока при <= 7 дней задаётся
core/time.h. Не создавай HWND и не выполняй сетевые запросы при отрисовке.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
