# config

settings.h загружает настройки через API Windhawk и выдаёт GetSettingsSnapshot
под g_settingsMutex. Тип Settings и объект g_settings принадлежат core/state.h.

Сохраняй имена настроек и переменных окружения, значения по умолчанию и безопасный
диапазон интервалов/таймаутов. Каждый refresh использует один snapshot настроек.
Изменение настроек сначала завершает и отменяет текущие задачи в integration,
затем применяет новые значения. Не читай изменяемые настройки напрямую из сети.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
