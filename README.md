# Codex LB Taskbar Dashboard

Модификация Windhawk для Windows 11: показывает оставшийся процент usage
codex-lb на панели задач. По нажатию открывает popup с аккаунтами, лимитами,
Reset и текущей/новой версией codex-lb, включая beta-релизы GitHub.
Проверена с Windhawk 1.7.3.

## Как подключить

1. Скопируйте **всю папку проекта** в постоянное место на диске.
2. В корневом mod.wh.cpp измените только путь после -I в @compilerOptions,
   сохранив остальные параметры и кавычки:
   `-I"D:/Media/User/source/repos/windhawk-codex-lb-taskbar-dashboard"`.
3. В Windhawk нажмите «Создать модификацию» и замените шаблон всем содержимым
   корневого mod.wh.cpp. Для обновления откройте исходник существующего мода.
4. Сохраните файл, скомпилируйте и включите модификацию. Если сначала нужна
   только проверка сборки, перед компиляцией выключите переключатель включения.
5. В настройках мода укажите адрес своего codex-lb. Данные входа и API-ключ
   сохраните в пользовательских переменных окружения CODEX_LB_DASHBOARD_USERNAME,
   CODEX_LB_DASHBOARD_PASSWORD и CODEX_LB_API_KEY. Инструкция и команда настройки
   приведены в описании мода в mod.wh.cpp.

**Папку проекта не удаляйте:** Windhawk читает заголовки из неё при каждой сборке.
Пароли, API-ключи и настройки получателя в архив/Git не добавляйте.

## Как обновлять и передавать

Основной файл — mod.wh.cpp **в этом проекте**. EditorWorkspace — временная рабочая
копия Windhawk. Правьте основной файл и src, сохраняйте заголовки, затем переносите
содержимое mod.wh.cpp в редактор Windhawk и компилируйте заново. Если правили
исходник через UI Windhawk, перенесите изменения обратно в проект.

Для передачи или резервного копирования достаточно всей папки проекта: отдельный
файл из EditorWorkspace больше не нужен. .git, кеши, локальный
editor/compile_commands.json и результаты сборки для установки не требуются.
Штатное сохранение/черновики Windhawk сохраняют только файл входа, без заголовков.

## Что внутри

- mod.wh.cpp — метаданные, описание, настройки и точки входа.
- src — реализация в .h: core, config, network, accounts, versions, ui, integration.
- tests — regression harness, изолированный режим --offline.
- editor и .clangd — необязательная настройка подсказок clangd.
- AGENTS.md в рабочих папках — назначение модулей и правила сопровождения.

Сборка остаётся одной единицей трансляции; собственной системы сборки нет.
Windhawk передаёт исходник через stdin из Compiler, поэтому include-путь нужен
в @compilerOptions. Пути с пробелами поддерживаются в кавычках. Подробности
clangd и его обновления — в editor/AGENTS.md. Изменение одних заголовков может
не включить индикатор изменённого мода; при необходимости добавьте пустую строку
в рабочий файл входа перед компиляцией.
