# tests

regression.cpp — существующий C++ harness с LocalHttpServer и режимом --offline.
Он включает production headers; не копируй реализацию в тесты.

--offline запускает проверки weekly/monthly/reauth, Reset/сроков, SemVer/beta,
latest-индикатора, alpha/DPI/scrolling, адреса и escaping login JSON без сети/окон.
Проверки popup различают ошибку, неизвестную текущую версию, равный/старый релиз
и новую beta; проверяют цвет, точный тег/URL и области клика ссылок;
значок GitHub ведёт на /releases, тег — на /releases/tag/<тег>.
Второй значок рядом с версией мода проверяется отдельно: URL репозитория мода,
точка внутри значка, вне значка и правая граница его области.
GDI-проверка значка создаёт только DIB в памяти: заполнение, сглаживание и
границы рисунка проверяются при 96/144/192 DPI без показа окна.
Offline-проверка диагностики GitHub покрывает извлечение message без посторонних
полей, не-JSON/пустой ответ, неверный тип, переносы строк и ограничение длины.
Также offline проверяет двухминутный минимум, primary/secondary limits,
Reset/Retry-After, неизменный цвет текста и рамки. Два параллельных клиента
SharedReleaseCache используют реальный именованный mutex и временный JSON-файл:
проверяется единственная резервация, общий результат, повторное открытие и отмена.
Временный кеш удаляется; пользовательский кеш и реальные HTTP-запросы не затрагиваются.
Обычный запуск без аргумента создаёт локальный HTTP-сервер и проверяет snapshot,
URL, cancellation в headers/body, общий deadline и manual refresh pause.
Не запускай сетевой набор без отдельного разрешения.

Standalone harness компилируется с WH_EDITING (штатные заглушки API Windhawk),
библиотеками мода (включая shell32) и ws2_32. Этот toolchain импортирует libc++.whl/libunwind.whl:
для тестового процесса нужны соответствующие compiler DLL под этими именами
рядом с exe. Артефакты тестов не хранить в Git.
Для x64 harness брать DLL из Compiler/x86_64-w64-mingw32/bin, а не Compiler/bin:
в установленном toolchain Compiler/bin содержит x86 DLL, несовместимые с x64 exe.
Для запуска компилятора/test exe нужно разрешение на точную команду,
включая --offline; frontend-исключение к этому
C++ harness не относится. Добавляй поведенческие тесты, не проверки структуры.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
