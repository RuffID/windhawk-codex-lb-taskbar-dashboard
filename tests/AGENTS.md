# tests

regression.cpp — существующий C++ harness с LocalHttpServer и режимом --offline.
Он включает production headers; не копируй реализацию в тесты.

--offline запускает проверки weekly/monthly/reauth, Reset/сроков, SemVer/beta,
latest-индикатора, alpha/DPI/scrolling, адреса и escaping login JSON без сети/окон.
Обычный запуск без аргумента создаёт локальный HTTP-сервер и проверяет snapshot,
URL, cancellation в headers/body, общий deadline и manual refresh pause.
Не запускай сетевой набор без отдельного разрешения.

Standalone harness компилируется с WH_EDITING (штатные заглушки API Windhawk),
библиотеками мода и ws2_32. Этот toolchain импортирует libc++.whl/libunwind.whl:
для тестового процесса нужны соответствующие compiler DLL под этими именами
рядом с exe. Артефакты тестов не хранить в Git. Для запуска компилятора/test exe
нужно разрешение на точную команду, включая --offline; frontend-исключение к этому
C++ harness не относится. Добавляй поведенческие тесты, не проверки структуры.

## Актуальность

При изменении кода, тестов или конфигурации этой папки в той же задаче обновляй
этот AGENTS.md: описание файлов, зависимостей и правил должно соответствовать
результату. При изменении структуры актуализируй также AGENTS.md родительской
папки. Это правило для работы над проектом, а не автоматическое слежение за файлами.
